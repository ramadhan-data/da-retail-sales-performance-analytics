# Data

`Online Retail - Indonesia.csv` is the raw file used in this project, stored here unchanged (52.7 MB).

- Source: https://github.com/satriaadi9/retail_sales/blob/main/Online%20Retail%20-%20Indonesia.csv
- Size: 495,478 rows x 9 columns (InvoiceNo, InvoiceDate, CustomerID, Country, Region, categories, Product Description, Quantity, UnitPrice)
- Period: 2024-12-01 to 2025-12-09 (last month partial)
- Currency: not stated in the file
- Region and Country each contain a single value; there is no cost or profit column

Provenance and licence were not verified. The file is included for reproducibility only; it is not claimed to be data from a real company. If the source owner objects, it will be removed.
