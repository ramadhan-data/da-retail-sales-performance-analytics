# Data

The raw file `Online Retail - Indonesia.csv` is **not included** in this repository: its origin and licence could not be verified.

- Source used for this project: https://github.com/satriaadi9/retail_sales/blob/main/Online%20Retail%20-%20Indonesia.csv
- Size: 495,478 rows x 9 columns (InvoiceNo, InvoiceDate, CustomerID, Country, Region, categories, Product Description, Quantity, UnitPrice)
- Period: 2024-12-01 to 2025-12-09 (last month partial)
- Currency: not stated in the file
- Region and Country each contain a single value; there is no cost or profit column

To reproduce the analysis, download the file from the source above and compare it with the `Raw_Data` sheet of the workbook.
